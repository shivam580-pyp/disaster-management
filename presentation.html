6. Feature Focus: Web Bluetooth & Local Wi-Fi Mesh Relay

Zero-Cellular Communication Pipeline

⚙️ 16-Byte Binary Frame Layout

  • Header (2 Bytes): Protocol Magic ID 0x4E 0x44 (ND).
  • Device ID (4 Bytes): Compressed MAC / Hash.
  • Triage & People (2 Bytes): Urgency level & victim count.
  • Coordinates (6 Bytes): Fixed-point Lat/Lng.
  • Hop Count (2 Bytes): Tracks relay hop distance.

🔄 Store-and-Forward Relay Protocol

  • BroadcastChannel: Instantly syncs distress calls across devices on local Wi-Fi router.
  • Web Bluetooth Beacon: Scans adjacent smartphones within 30-50m range.
  • Auto Server Upload: Flushes queued signals to server the moment any device regains network.
